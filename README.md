# softproject

Sitio web corporativo de **softproject** (softproject.qzz.io): desarrollo de software
a medida para web, móvil y escritorio, con backend y mantenimiento.

## Stack del sitio

Astro 5 + React + TypeScript, con i18n ES/EN y tema modular (glassmorphism).

## Desarrollo

```bash
pnpm install
pnpm dev      # → http://localhost:4321
pnpm build    # estático en dist/
pnpm check    # type-check
```

Lee `MANIFEST.md` para las reglas de diseño y arquitectura antes de modificar algo.
